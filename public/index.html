Registration Guidelines

  1. Enter accurate student information.
  2. Use a valid roll number.
  3. Team members must have unique roll numbers.
  4. Select the correct section.
  5. Select the correct date and time.
  6. Verify information before submitting.
  7. Students should arrive before the presentation time.
